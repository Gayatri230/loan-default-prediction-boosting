->Project Title

Loan Default Prediction using Boosting Techniques

* Project Description 

In this project, I built a machine learning model to predict loan approval outcomes using real-world financial data.

The goal was to compare traditional decision tree models with ensemble learning techniques, specifically Random Forest (Bagging) and Gradient Boosting (Boosting), to understand how ensemble methods improve model performance and generalization.

The models were evaluated using classification metrics and confusion matrix analysis, with a strong focus on business impact, particularly minimizing risky loan approvals
